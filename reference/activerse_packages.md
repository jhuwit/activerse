# List the packages in the activerse

Returns the names of the packages that are attached when activerse is
loaded with [`library()`](https://rdrr.io/r/base/library.html).

## Usage

``` r
activerse_packages()
```

## Value

A character vector of package names.

## Examples

``` r
activerse_packages()
#> [1] "actibase"        "actiplot"        "actiread"        "actimetrics"    
#> [5] "actisensorlog"   "actisomni"       "actiwalkability" "actiquantiles"  
```
